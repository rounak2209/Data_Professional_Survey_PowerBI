# 📊 Data Professional Survey Breakdown

## 📝 Overview
This repository contains an end-to-end Power BI dashboard project that analyzes survey data from data professionals. The goal of this project is to provide actionable insights into the data industry, including salary trends, popular programming languages, job satisfaction, and demographic breakdowns.

Before building this interactive dashboard, the data was explored and understood using Advanced Excel. While I frequently use Python (Pandas, Matplotlib, Seaborn) and MySQL for programmatic data analysis, this project specifically focuses on utilizing **Power BI's native capabilities** for data modeling, DAX measure creation, and visual storytelling.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For Data Visualization and UI/UX design.
* **Power Query:** For data transformation, cleaning, and shaping.
* **DAX (Data Analysis Expressions):** For creating complex measures and calculated columns.
* **Advanced Excel:** For initial dataset review and storage.

## 💡 Key Features of the Dashboard
* **Dynamic UI/UX:** Interactive slicers and page navigation for a seamless user experience.
* **Cross-Filtering:** Selecting a specific visual element (e.g., a specific job title like 'Data Analyst') dynamically filters all other charts on the page.
* **Salary Analysis:** Breakdown of average salaries by job role, experience, and region.
* **Demographic Insights:** Visualizations showing the distribution of respondents by age, gender, and education level.
* **Technical Preferences:** Analysis of the most popular programming languages and tools used by professionals in the field.

## 📂 Files in this Repository
* `Data Professional Survey Breakdown.pbix`: The main Power BI project file containing the data model and dashboard.
* `Power BI - Final Project.xlsx`: The raw dataset used for this analysis.

## 🚀 How to Use / Interact with the Dashboard
Since this is a `.pbix` file, you will need Power BI Desktop to open and interact with it:
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Free).
2. Clone this repository or download the `.pbix` file directly.
3. Open the file in Power BI Desktop to explore the data model, DAX formulas, and interactive visuals.
